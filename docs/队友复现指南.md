# 队友下载后的复现指南

## 随附数据与边界

当前随附快照为 **72篇阅读、360题、1362句、6份拆句缓存**。英语一涵盖2018—2026，英语二涵盖2018—2026；每卷仅阅读Part A四篇20题，不是整卷全部题型。原王世豪阶段交付为68篇340题；团队后续补入2020英语一20题，不能混同个人贡献。

题干、选项、提供的答案、解析与步骤来自随附资料。所有360题仍是基础练习口径，不代表全部经过人工教学审核。当前快照定位状态：141题exact_quote、76题multi_sentence、143题pending；字符匹配不等于证据在语义上支持答案，也不承诺自动高亮已完成。

以后扩容不应修改安装脚本中的固定题数。安装入口应校验快照声明数量、实际数组、关联及题号，再根据本次快照验收；具体见[质量保障交付说明](王世豪-题库质量保障.md)。

## 首次安装（Windows PowerShell）

先安装Python与Node.js，并在项目根目录建立独立Python虚拟环境。以下为本机操作示例，不要求全局安装Python包：

```powershell
py -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r server/requirements.txt
.\.venv\Scripts\python.exe server/scripts/setup_team.py
cd server
..\.venv\Scripts\python.exe -m uvicorn app:app --host 127.0.0.1 --port 8000
```

安装程序只接受不存在的目标数据库。恢复、发布校验和完整性检查先在隔离临时库完成，成功才发布目标；失败不应留下半成品目标。开放基础练习会记录审计，但不会伪造人工审核记录。

另开终端，在项目根目录：

```powershell
cd web
npm ci
npm run dev -- --host 127.0.0.1
```

浏览器打开终端显示的地址（默认 http://127.0.0.1:5173 ）。后端使用8000端口，两端终端均需保持运行。阅读、答题、已有解析、学习记录使用本地数据库，不要求重新处理PDF或调用模型。根目录的旧启动脚本启动的是Streamlit旧版，不是这里的React工作台。

## 已有数据库

不要删除已有数据库或用旧恢复命令覆盖个人记录。先停服务并备份数据库及相关SQLite侧文件，再由维护者按迁移方案操作。`setup_team.py`拒绝覆盖已有目标；它是首次安装工具，不是现有数据库升级工具。`load_demo.py`是底层恢复工具，会重置审核与发布状态，不应随意执行`--reset`。

## 运行前质量检查

在项目根目录用同一虚拟环境运行：

```powershell
.\.venv\Scripts\python.exe server/scripts/audit_question_bank.py --help
.\.venv\Scripts\python.exe -m unittest discover -s server/tests -t server
```

审计只读输入；JSON/Markdown输出使用新文件名，保留历史。报告中的待核验事项不是程序已证明的错误，更不能为清零而随意改题号、答案或句子ID。

## 与开发机的差异

- 不共享个人作答、单词本、Agent历史、密钥、原始PDF、虚拟环境或node_modules；seed可能建立仓库演示状态，它不是个人历史。
- 仅6份既有句子拆解缓存可复用。其他拆句和开放问答需要队友配置自己的API；配置变更后重启后端。无Key并不阻止基础题库练习，但不能保证新句模型输出。
- 后台为本地演示用途，公网部署前必须修改默认管理员Token并评估身份隔离、安全与数据许可；GitHub仓库不是在线运行地址。
- 材料用于课程交流；公开分发原文与第三方解析前，须确认具有相应许可。
