# UI 优化记录（2026-10-23）

整合当日四份按时间记录的问题清单（20:24 / 20:47 / 21:12 / 21:58），按主题归类，全部已处理。

## 一、新增浏览能力

### 1. 缺少词库与真题库的浏览页面

**原始问题（20:24）**

> 没有能都对词库和真题库直接进行浏览的页面，希望添加直接进行浏览的导航。

**处理**

- 新增「资料库」页面，包含两个 Tab：
  - **大纲词汇**：5,064 条全量分页浏览，支持关键词搜索、等级筛选（基础 4,400 / 核心 55 / 拔高 609）、按字母或频次排序
  - **真题篇章**：卡片式展示年份、试卷、Text 号、词数、句数、题数，「去做题」可直达该篇
- 新增后端接口 `GET /api/vocab`（分页、筛选、排序）

### 2. 浏览页缺少「添加词汇」入口

**原始问题（20:24）**

> 在对应词库浏览页面增加"添加词汇"按钮，对浏览的词汇可以直接进行添加操作，将词汇添加到我的单词本。

**处理**

- 词库列表每行右侧增加「加入单词本」按钮，调用现有 `POST /api/wordbook`
- 已收藏的词自动变为灰色「已在单词本」，避免重复添加

### 3. 词库缺少快速跳页

**原始问题（20:47）**

> 词汇库查看词汇没有快速跳页，希望排序后的词汇库，在底部增加选页按钮和直接输入页码的输入框，方便快速跳页。

**处理**

- 底部分页条改为：上一页 / 最多 5 个页码按钮 / 下一页
- 右侧增加「跳到 [ __ ] 页」输入框，支持回车跳转，越界自动夹到首末页
- 搜索、切等级、改排序时自动回到第 1 页

## 二、交互修正

### 4. 首页指标卡不可点击，反直觉

**原始问题（20:24）**

> 首页四个分类按钮无法交互，反直觉。应该能点击对应"真题篇章""大纲词汇""单词本""已练习"，然后跳转到对应材料库开始浏览。

**处理**

- 四个指标卡全部支持点击，并带悬停浮起效果：

| 卡片 | 跳转目标 |
| --- | --- |
| 真题篇章 | 「资料库」真题篇章 Tab |
| 大纲词汇 | 「资料库」大纲词汇 Tab |
| 我的单词本 | 「我的单词本」页 |
| 已练习 | 「学习报告」页 |

- 阅读训练页同步支持按年份、试卷、Text 深链定位，从真题库点「去做题」会精确打开对应篇章，而不是回到第一篇

### 5. 单词本缺少即时复习入口

**原始问题（21:12）**

> 希望在我的单词本里添加"开始复习"的功能，立刻开始进行复习。复习的词汇是使用我的单词本的词汇随机生成一个序列，然后开始复习单词释义，复习形式参考原先的每日复习的形式。

**处理**

- 「我的单词本」顶部新增「开始复习」按钮
- 点击后将单词本全部词汇随机洗牌，直接进入复习视图，不受到期日限制
- 复习形式复用每日复习：显示单词 → 点击显示释义 → 选择「记住了 / 没记住」
- 复习结果仍会更新掌握度与下次复习时间；单词本为空时按钮置灰

## 三、文案与导航

### 6. 「单词本」改名为「我的单词本」

**原始问题（20:24）**

> 把"单词本"改为"我的单词本"，便于和词库进行区分。

**处理**

- 侧边栏导航、页面标题、首页指标卡、首页功能卡统一改为「我的单词本」

### 7. 「选项陷阱分析」与落地页名称不一致

**原始问题（20:47）**

> 主页核心功能中"选项陷阱分析"跳转到"阅读训练"功能页，容易混淆，把主页核心功能中的"选项陷阱分析"改为"阅读真题训练（选项陷阱分析）"。

**处理**

- 首页功能卡标题改为「阅读真题训练（选项陷阱分析）」，与落地页名称对齐

### 8. 「资料库」导航位置调整

**原始问题（21:58）**

> 把左侧"资料库"导航调整到"我的单词本"下方。

**处理**

- 导航顺序调整为：首页 / 长难句拆解 / 阅读真题训练 / AI 对话 / 我的单词本 / 资料库 / 学习报告 / 领域知识库

### 9. 导航视觉层级不清

**原始问题（21:58）**

> 把左侧栏四个主要功能（长难句拆解、阅读训练、AI 对话、我的单词本）的导航字体改成金色，把"首页"导航的按钮增大，使其在左侧导航栏更显眼，增加阴影和反色选中逻辑。

**处理**

- 三层视觉分级：

| 层级 | 项目 | 样式 |
| --- | --- | --- |
| 主入口 | 首页 | 深色实心块，更大的内边距与字号、加粗、图标放大 |
| 核心功能 | 长难句拆解、阅读真题训练、AI 对话、我的单词本 | 琥珀金色文字与图标，选中时金底白字反色 |
| 辅助页 | 资料库、学习报告、领域知识库 | 灰色文字，保持克制 |

- 全部导航项统一「1px 浅灰描边 + 同强度投影 + 白底」的卡片质感，间距调至 6px
- 选中状态统一采用底色与文字反色逻辑；非选中状态下首页为白底描边，避免黑色块被误认为"已选中"
