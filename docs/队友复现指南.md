# 队友下载后的复现指南

本分支包含本地开发版的功能代码及共享题库，不只是空项目。尚未提交或推送时，GitHub 下载仍是旧版本；须先完成提交、推送，再由队友下载相应分支。

## 包含的数据

- 68篇完整阅读、340道题、1295句、6份已有拆句缓存。
- 每题题干、A—D选项、答案、四选项解析及解题步骤。
- 英语一：2018、2019、2021—2026；英语二：2018—2026。每卷阅读Part A四篇20题，不包含整卷其他题型。
- 原2023/2024英语一40题保留；新增15卷300题的解析来自所提供PDF。34题原资料无独立【定位】字段，未伪造定位；现阶段不承诺自动句子高亮与原卷坐标一致。

## 首次安装（Windows PowerShell）

在项目根目录建立独立Python环境并按 server/requirements.txt 安装依赖，然后进入server：

```powershell
cd server
python scripts/setup_team.py
python -m uvicorn app:app --host 127.0.0.1 --port 8000
```

确保这里的python是已安装后端依赖的虚拟环境解释器。首次准备命令会恢复随附快照、校验全库，并通过现有发布流程开放68篇340题的基础练习，记录安装操作审计，不冒充人工解析审核。

另开终端，在项目根目录：

```powershell
cd web
npm ci
npm run dev -- --host 127.0.0.1
```

浏览器打开终端显示的地址（默认 http://127.0.0.1:5173）。后端使用8000端口。阅读、选项答题、现成解析和学习记录保存可使用本地数据库，不要求重新跑PDF或模型。

## 已有数据库的队友

setup_team.py 检测到数据库已存在会拒绝覆盖，保护已有题库及学习记录。不要为了执行此命令直接删除自己的数据库。先停止服务、备份数据库，再按建库操作说明迁移；load_demo.py会将恢复的内容重置草稿，不要在有个人记录的数据库上随意重复恢复或使用--reset。

## 与原开发机的差异

- 不共享原开发机个人作答、单词本、Agent会话历史或密钥；seed会生成仓库自带的演示学习状态，不是王世豪的个人历史。
- 原始PDF、Python环境、node_modules、构建产物不提交；队友自行安装依赖。
- 仅6份已有句子拆解缓存可复用；其他句子的模型拆解、开放问答等仍需队友配置自己的API。无密钥不保证这些功能与开发机外部模型输出相同。
- 全部题目供基础练习，不代表全部解析已完成人工教学审核。
- 来源/页码信息保留于题库。材料用于课程小组交流；原资料注明内部使用。公开推送全文及第三方解析前，应确认拥有相应分发许可；本次只完成本地合并，未替你上传。
