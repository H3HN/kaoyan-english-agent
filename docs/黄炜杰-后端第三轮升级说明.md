## 1. 任务 A：exam_passages 唯一约束与历史重复清理

**改动文件**

- `server/db.py`
  - `SCHEMA.exam_passages` 增加表级 `UNIQUE(year, exam_type, text_number)`，新库直接生效。
  - 新增 `delete_draft_passage()` / `delete_draft_slot()`：只删 `draft` 且无 `practice_records` 引用的篇章，按“拆解缓存 → 题目 → 句子 → bank_events → 篇章”顺序删子记录；有历史引用时抛明确 `RuntimeError`。
  - `migrate_schema()` 末尾调用 `_ensure_unique_passage_slot()`：清理同键重复 draft，复查仍重复则中止，再建 `ux_exam_passages_slot` 唯一索引。
- `server/scripts/load_demo.py`：快照导入前调用 `delete_draft_slot()`，避免同槽位示例草稿与 68 篇快照在唯一约束下冲突。
- `server/seed.py`：`_seed_exams()` 改为“槽位已占用则跳过示例”，不再 `INSERT OR REPLACE` 覆盖真实题库；只插入本次新建示例的句子/题目。
- `server/question_bank.py`：导入真实题库时，先删除同槽位的两个内置示例草稿（仅限无引用的 `2023_en1_t1` / `2024_en1_t1`），再插入 `bank_*`。

**关键决策**

- 只自动删除“draft 且无 practice 引用”的重复行；已发布重复或带学习历史的草稿不静默处理，直接报错。
- `setup_team.py` 走 `load_demo`，因此在恢复前清理示例槽位；全新建库仍得到 68 篇 / 340 题 / 1,295 句。
- 现有 `app.db` 已执行迁移：重复组从 2 组降为 **0**，篇章 70→**68**，published 仍为 **68**。

**测试**

- 新增 `server/tests/test_unique_constraint.py`（4 项）：旧库清理幂等、迁移后重复插入 `IntegrityError`、带 practice 历史的草稿阻止清理、新库表级约束生效。
- 更新 `test_question_bank.py` 的占位断言：真实 2024 Text 1 导入后，示例占位被删除，篇数由 3 改为 2。

## 4. 任务 D：CORS 白名单 + X-Request-ID

- `server/app.py`
  - `CORS_ORIGINS` 环境变量（逗号分隔），默认 `http://127.0.0.1:5173,http://localhost:5173`。
  - `add_request_id` 中间件：优先复用请求头 `X-Request-ID`，否则 `uuid4().hex[:12]`；写回响应头。
  - 异常处理器改为 `StarletteHTTPException`：404/400 等 `detail` 变为 `{message, request_id}`；**410 保持原字符串契约**。
- `server/.env.example` 增加 `CORS_ORIGINS` 示例。

**测试**

- 新增 `server/tests/test_request_id.py`（7 项）：200/404 头、客户端 ID 回显、404 detail request_id、410 契约、允许本地 Origin、拒绝未知 Origin、环境变量覆盖。
