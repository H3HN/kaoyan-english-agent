## 1. 这次解决什么问题

交接文档要求：为 340 题补充 `source_sentence_id` / `location_status`，"无可靠证据时维持待确认，不随机指定第一句或最长句"。

原状态的问题：快照恢复（`load_demo.py`）对定位字段**原样照抄**，340 题全部停留在 `unverified`，学生端 `/api/questions/full` 全部显示"待人工定位"，`app.py` 中已实现的 exact_quote 展示逻辑（`location` / `sourceSentence` / `sourceSentenceId`）没有数据可用。

## 2. 方案设计

新增模块 `server/evidence_locator.py` 与 CLI `server/scripts/locate_evidence.py`。核心原则：**完全复用 `exam_import.locate_quote` 的既有匹配语义，不新造定位算法**。

### 2.1 为什么不直接用句子表里的偏移

快照中 145 句（原 auto 导入的 8 篇）`char_start/char_end` 为 NULL；另有 6 篇 auto 篇章的旧切分与当前 `split_passage` 结果不一致（旧导入切分逻辑不同）。因此不以存储偏移为准。

### 2.2 可靠句子偏移

以**数据库句子表 + 文章原文**为准，规则：

- 每个句子文本在 passage 中用空白容错正则检索（与 `locate_quote` 对引文的匹配方式一致）；
- **恰好出现一次** → 该句子获得可靠偏移，参与题目绑定；
- 出现 0 次或多次 → 不参与绑定（重复句永远不绑定）。

实测：1295 句中 1294 句可靠，仅 1 句因文本重复排除。

### 2.3 题目定位

对每题调用 `locate_quote(source_quote, passage, 可靠句子行)`，状态语义与建库时完全一致：

| 状态 | 含义 | 本次数量 |
| --- | --- | --- |
| exact_quote | 引文唯一出现且完整落在单个可靠句内，绑定该句 | **141** |
| multi_sentence | 引文唯一出现但横跨多句，不强行绑定 | 76 |
| ambiguous | 引文多处出现 | 0 |
| pending | 引文缺失 / 过短 / 无法匹配 | 123（74 无引文 + 49 引文差异） |

### 2.4 安全边界

- 只更新 `exam_questions.source_sentence_id` / `location_status` 两个字段；
- **不改动** `publication_status` / `review_status` / `revision` / 解析内容——已开放的基础练习无感升级，`setup_team.py` 的发布校验不受影响；
- 顺带回填 auto 篇章 NULL 偏移句子的 `char_start/char_end`（仅唯一出现者，144/145 句），重复句保持 NULL；
- 每篇写一条 `bank_events` 审计（action=`evidence_located`，含每题 before/after 快照）；
- `--dry-run` 只算不写；幂等可重复执行。

## 4. 留给人工复核的清单（按优先级）

1. **76 题 multi_sentence**（引文跨句）：按 `readiness` 契约填写 `evidence_note` 说明跨句/全文证据即可过审核，无需强行绑定单句。集中在 Text 3（最多篇章 4 题）。
2. **49 题 pending（有引文但未唯一匹配）**：根因是**引文与正文的标点/符号规范化差异**——16 题有明确词差异（全角引号「」“”、全角括号（、词尾标点粘连如 `done.`、`（H-2A`），33 题为整体拼接差异。处理方式二选一：
   - 人工逐题修 `source_quote` 为逐字摘录（保守，符合"verbatim"原则，推荐）；
   - 或团队决策后给 `locate_quote` 增加"剥离非字母数字字符"的容错匹配（可自动化，但有 `U.S.`→`US` 类假阳性风险，需评审）。本次未改动匹配语义。
3. **74 题 pending（无引文）**：原资料无独立【定位】字段，需人工从原文补摘引文，程序不生成。

## 5. 使用方法

```bash
cd server
# 先看统计，不写库
python scripts/locate_evidence.py --actor "操作人" --dry-run
# 正式执行（幂等，可重复）
python scripts/locate_evidence.py --actor "操作人"
# 只处理指定篇章
python scripts/locate_evidence.py --actor "操作人" --passages bank_2018_1_1
# 独立试跑（不动 app.db）
python scripts/locate_evidence.py --database data/bank-trial.db --actor "操作人"
```

对已按旧快照装好环境的队友：直接在自己库上跑一遍即可获得同样的定位结果（确定性、幂等）；或删除旧库后用新快照 `setup_team.py` 重装。
